# Ultimate Tic-Tac-Toe

A beautiful, pastel-themed implementation of **Ultimate Tic-Tac-Toe**, featuring a smart AI opponent powered by the Minimax algorithm with Alpha-Beta pruning. 


## Features
* **Smart AI Engine:** Powered by a highly optimized Python Minimax bot (`minimax_ttt.py`).
* **Adjustable Difficulty:** Choose between Fast (Depth 3), Normal (Depth 5), or Strong (Depth 7) AI thinking limits.
* **Aesthetic UI:** Soft pastel colors, responsive glowing SVG art, and smooth CSS animations.
* **Full UTTT Rules:** Automatically enforces macro-board targeting, valid move highlighting, and "free choice" states.
